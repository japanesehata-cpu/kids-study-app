# 用語集

ドキュメント・コード・会話で使う用語を統一するための一覧。表記揺れを避けるため、ここに載っている表記を正とする。

## ドメイン用語

### 学習の単位
| 用語 | 読み | 英語／コード上の名前 | 定義 | 使用例 |
|---|---|---|---|---|
| カテゴリ | かてごり | `Category` | 学習内容の種類。学習記録と★レベルはカテゴリごとに持つ | たしざん、まちがいさがし |
| 区分 | くぶん | － | カテゴリのまとまり。算数・ことば・考える力の3つ | ことば：ひらがな・漢字・えいご |
| 入口画面 | いりぐちがめん | `〇〇EntryScreen` | 1つのホームのカードから、複数のカテゴリやモードを選ばせる画面 | もじの入口から ひらがな を選ぶ |
| モード | もーど | `mode`、`ClockMode`、`SudokuMode` | 同じカテゴリの中の遊び方の違い。★レベルとは別 | とけいの「選択肢から選ぶ／針を合わせる」 |
| ★レベル | ほしれべる | `Level`（1〜6） | 難しさの段階。1つのレベルは1つのはっきりした難しさを持つ | たしざん★3 |
| 最大★ | さいだいほし | `CATEGORY_MAX_LEVEL` | カテゴリごとのレベルの上限（1〜6） | ろんりの最大★は4 |
| 到達レベル | とうたつれべる | `CategoryProgress.level` | 子どもが今いるレベル。条件を満たすと1つ上がる | 到達レベルが★2から★3になった |
| レベルアップ | れべるあっぷ | `leveledUp` | 到達レベルで遊んだ直近2セットがどちらも正答率80%以上のとき、到達レベルが1つ上がること | － |
| セット | せっと | `setSize`、`SetResult` | 続けて出す問題のまとまり。5もん または 10もん | 10もんのセットを終えた |
| 問題 | もんだい | `Question` | 1問分の内容（問い・選択肢・正解）。形はカテゴリごとに違う | － |
| 出題範囲 | しゅつだいはんい | `〇〇Bank`（例：`kanjiBank`） | 問題の材料となる文字・単語・場面などのデータ | 漢字の出題範囲 |
| 問題の生成 | もんだいのせいせい | `questionGenerators/`、`generate〇〇Question` | 出題範囲とレベルから、その場で1問を組み立てること | － |
| 問題の種類 | もんだいのしゅるい | `subSkill` | 1つのカテゴリの中の、問われる力の細かい区別。結果画面の「得意・苦手」に使う | くり上がりのある たしざん |
| 正答率 | せいとうりつ | `accuracy` | セットの中で正解した問題の割合 | － |
| 連続正解 | れんぞくせいかい | `streak`、`bestStreak` | 続けて正解した問題の数。3問から演出が強くなる | 「5もん れんぞく！」 |
| 復習リスト | ふくしゅうりすと | `reviewQueue` | まちがえた問題の一覧（最大12問）。次のセットに入り、正解すると外れる | － |
| 直近の出題 | ちょっきんのしゅつだい | `recent`、`recencyKey` | 直近に出した問題の記録（最大40件）。同じ問題が続かないように使う | － |
| 学習記録 | がくしゅうきろく | `ProgressState`、`CategoryProgress` | カテゴリごとの到達レベル・正答率・復習リスト・直近の出題。端末内に保存する | － |
| 進み具合 | すすみぐあい | `ProgressScreen` | 保護者向けに学習記録を見せる画面 | － |
| 保護者ゲート | ほごしゃげーと | `ParentGate` | 2けたの足し算に正解した人だけを、保護者向けの画面に通す仕組み | － |

| 書き順データ | かきじゅんでーた | `〇〇Strokes`（例：`kanjiStrokes`） | 1画ずつの線の形と順番。なぞり書きの判定に使う | － |

### まちがいさがし
| 用語 | 読み | 英語／コード上の名前 | 定義 | 使用例 |
|---|---|---|---|---|
| テーマ | てーま | `SpotTheme`、`spot/<テーマ>/` | 1つの場面の種類（30種）。背景と物の画像の組 | もり、うみ |
| 物の画像 | もののがぞう | スプライト（sprite）、`<物>.png` | 背景の上に置く、背景が透明な1つの物の画像 | きつね |
| 違い | ちがい | `SpotDifferenceItem` | 上下2枚の絵で異なる部分。子どもがタップして見つける | － |
| 色ちがい | いろちがい | `recolor`、`<物>__color.png` | 物の色だけを変えた違い | － |
| 部分ちがい | ぶぶんちがい | `part`、`<物>__part.png` | 物の一部（模様・形）を描き変えた違い | 物に星の模様がつく |
| 背景のちがい | はいけいのちがい | `bg__<id>.jpg` | 背景の一部を描き変えた違い。作り方は方式 A（画像処理、id は `d<N>`）と方式 B（AI での描き直し） | － |

## 技術用語
| 用語 | 定義 | 本プロジェクトでの使われ方 |
|---|---|---|
| PWA | ホーム画面に追加でき、オフラインでも動く Web アプリ | 配布形態。親のスマホのホーム画面に追加して使う |
| Service Worker | ページの裏で通信をとりもち、ファイルをキャッシュする仕組み | 画面・画像・音声をキャッシュし、オフライン動作と自動更新を行う |
| マニフェスト | PWA の名前・アイコン・画面の向きなどの設定 | `vite.config.ts` の中で定義する |
| localStorage | ブラウザの中の小さな保存領域 | 学習記録・表示言語・BGM 設定を保存する |
| Web Audio API | ブラウザで音を作ったり再生したりする仕組み | 効果音・BGM の合成と、事前音声の再生 |
| Web Speech API | ブラウザの音声合成 | 事前音声がない文の読み上げ |
| FitToViewport | 画面が収まらないとき、画面全体を縮小して表示する部品 | スクロールをなくすための最後の手段 |
| エラー境界 | 描画中の例外を受けて、代わりの画面を出す React の仕組み | `AppErrorBoundary`。ホームへ戻れるようにする |
| i18n | 多言語対応 | `src/i18n/`。日本語と英語の表示文字列 |
| SDXL 系モデル | ローカルで動かす画像生成モデル（RealVisXL、DreamShaper XL Lightning） | キャラクターデザイン以外のすべての画像の生成 |
| インペイント | 画像の一部だけを描き直す画像生成の方法 | 部分ちがい・背景のちがい・まばたきの差分の生成 |
| VOICEVOX | ローカルで動かす日本語の音声合成エンジン | 日本語の事前音声の生成 |
| Kokoro／Piper | ローカルで動かす英語の音声合成エンジン | 英語の事前音声の生成 |
| KanjiVG | 漢字などの書き順の公開データ（CC BY-SA 3.0） | 書き順データの元 |
